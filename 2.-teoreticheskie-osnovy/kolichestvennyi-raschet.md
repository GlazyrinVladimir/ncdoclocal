# Количественный расчет

Количественный расчет является завершающей стадией обработки хроматографического сигнала. На данном этапе производится определение концентраций компонентов в анализируемой пробе с неизвестным содержанием анализируемых веществ.

## Цели количественного анализа

Выполнение количественного расчета в ПО «NetChrom» позволяет решать следующие аналитические задачи:

* Определение точного массового, объемного или молярного содержания индивидуальных компонентов в многокомпонентных смесях.
* Оценка чистоты технических продуктов и детектирование микропримесей.
* Автоматический расчет физико-химических показателей сложных сред (плотность, октановое число, теплота сгорания) на основе компонентного состава.

## Принцип расчета и выбор аналитического сигнала

Количественный расчет базируется на измерении аналитического отклика детектора для каждого идентифицированного компонента на хроматограмме. В качестве меры отклика (размера пика) в программе могут использоваться два основных параметра:

1. **Площадь пика (S)** — является интегральной характеристикой и наиболее надежным параметром. Площадь пропорциональна общей массе вещества, прошедшего через детекторы, и практически не зависит от незначительных колебаний температуры колонки и скорости потока газа-носителя. Рекомендуется для большинства хроматографических задач, особенно при анализе асимметричных или размытых пиков.
2. **Высота пика (H)** — представляет собой максимальный дифференциальный сигнал детектора над базовой линией. Высота пика критически чувствительна к малейшим изменениям условий разделения (температура, давление). Использование высоты допускается при экспресс-анализах узких, строго симметричных пиков, а также при определении следовых количеств веществ, когда точность интегрирования площади краев пика падает из-за флуктуаций шума.

Зависимость между измеренным откликом и количеством (концентрацией) вещества устанавливается на этапе градуировки прибора и математически описывается градуировочной функцией.

## Общий алгоритм выполнения количественного расчета

Процесс вычисления концентраций в ПО «NetChrom» выполняется автоматически в рамках текущего метода обработки и включает следующие последовательные этапы:

`[Регистрация сигнала] -> [Фильтрация и разметка базовой линии] -> [Интегрирование пиков (S, H)] -> [Идентификация компонентов по времени удерживания] -> [Вычисление концентраций по градуировочной функции] -> [Формирование отчета]`

1. **Интегрирование хроматограммы** — определение границ пиков, разметка базовой линии и автоматическое вычисление их площадей или высот.
2. **Идентификация пиков** — сопоставление времен удерживания зарегистрированных пиков с данными таблицы компонентов текущего метода анализа.
3. **Расчет концентраций** — применение выбранного математического метода (нормализации, внешнего стандарта и др.) с использованием индивидуальных градуировочных коэффициентов для каждого найденного компонента.
4. **Учет нерегистрируемых примесей** — корректировка результатов расчета на содержание веществ, которые не могут быть определены данным детектором, но их концентрация известна из сторонних физико-химических анализов.
5. **Вывод результатов** — формирование итогового протокола анализа с возможностью вывода на печать или экспорта данных в смежные системы.

## Классификация методов количественного расчета

В зависимости от способа сопоставления аналитического сигнала с градуировочными данными, а также от требований к воспроизводимости ввода пробы, в ПО «NetChrom» реализуются следующие базовые методы расчета:

* **Метод простой процентной нормализации** — содержание компонента определяется как процентное отношение его отклика к сумме откликов всех пиков на хроматограмме. Предполагает, что детектор одинаково чувствителен ко всем компонентам пробы.
* **Метод внутренней нормализации** — модификация простого метода нормализации, которая учитывает индивидуальные градуировочные коэффициенты (факторы чувствительности детектора) для каждого вещества.
* **Метод абсолютной градуировки (внешнего стандарта)** — расчет концентрации выполняется напрямую по индивидуальной градуировочной функции компонента. Метод требует строго постоянного и воспроизводимого объема вводимой пробы.
* **Метод внутреннего стандарта** — в пробу вводится фиксированное количество эталонного вещества. Расчет ведется по отношению отклика компонента к отклику стандарта, что полностью нивелирует ошибки ручного дозирования.
* **Метод стандартной добавки** — разновидность метода внутреннего стандарта, при которой в качестве эталона используется точно известное количество определяемого компонента, повторно вносимое в пробу.

## Критерии выбора метода расчета

Для быстрого выбора оптимального алгоритма расчета количественного состава в ПО «NetChrom» используйте следующую сравнительную таблицу:

| Метод расчета               | Зависимость от объема ввода пробы | Требование к регистрации всех пиков смеси | Главное аналитическое преимущество                                          |
| --------------------------- | --------------------------------- | ----------------------------------------- | --------------------------------------------------------------------------- |
| **Процентная нормализация** | Полностью отсутствует             | Да (обязательно 100%)                     | Максимальная простота, не требует калибровочных стандартов                  |
| **Внутренняя нормализация** | Полностью отсутствует             | Да (обязательно 100%)                     | Высокая точность для сложных смесей за счет учета факторов чувствительности |
| **Абсолютная градуировка**  | Критически высокая                | Нет (только целевые пики)                 | Позволяет определять отдельные целевые компоненты и микропримеси            |
| **Внутренний стандарт**     | Полностью отсутствует             | Нет (только целевой + стандарт)           | Исключает ошибки ручного ввода пробы и нестабильности потока газа           |
| **Стандартная добавка**     | Полностью отсутствует             | Нет (только целевой пик)                  | Эффективен при анализе следовых количеств в сложных, неизвестных матрицах   |
