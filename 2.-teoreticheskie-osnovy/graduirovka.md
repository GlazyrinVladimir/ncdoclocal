# ???Градуировка

Градуировка проводится с целью создания градуировочной зависимости, которая устанавливает количественную связь между величиной отклика детектора (размером пика — площадью или высотой) и содержанием компонента в пробе.

## Математическое описание

Общая форма градуировочной функции для компонента имеет вид:

$$Q = K_2 \cdot R^2 + K_1 \cdot R + K_0$$

Где:

* Q — количество (концентрация) компонента в пробе;
* R — отклик детектора (площадь или высота пика);
* K₀, K₁, K₂ — градуировочные коэффициенты компонента.

## Процесс градуировки

Для получения градуировочной зависимости выполняется анализ серии градуировочных смесей с известным содержанием компонентов:

* Концентрации компонентов в градуировочных смесях должны охватывать полный диапазон измерений, ожидаемых в анализируемых пробах.
* Серии измерений для каждой градуировочной смеси проводят не менее двух раз для повышения достоверности.
* По результатам измерений строятся градуировочные графики зависимости отклика от концентрации.

{% hint style="info" %}
Рекомендуется периодически контролировать стабильность градуировочной зависимости путем анализа контрольных образцов (шипованных проб) между рабочими сериями анализов.
{% endhint %}

## Рассчёт градуировочных коэффициентов

* При многоуровневой градуировке зависимость между сигналом детектора и концентрацией может иметь любую форму, не обязательно линейную.
* Коэффициенты градуировки определяются методом наименьших квадратов (МНК), подбирая функцию, максимально соответствующую экспериментальным данным.
* В программе оператор выбирает тип функции из набора стандартных моделей, при этом рекомендуемая к построению кривая не должна противоречить теоретически обоснованной зависимости для конкретного детектора.

### Особый случай — линейная градуировка через начало координат

Если градуировочная зависимость является линейной и проходит через начало координат (т.е. K₀ = 0), то её можно построить на основании данных одной градуировочной смеси (одного отбора):

$$Q = K_1 \cdot R$$

## Выбор параметра отклика детектора

* **Площадь пика** в большинстве случаев является более надёжным и устойчивым параметром отклика по сравнению с высотой.
* Однако если пики узкие и высокие, замеры **высоты** могут иметь меньшую ошибку.
* Высота пика не подходит для несимметричных или зависящих от условий анализа пиков.
* Выбор площади или высоты принимается с учётом свойств конкретного метода анализа.

### Использование относительных коэффициентов отклика

* При применении методов внутренней нормализации нередко используются заранее известные относительные коэффициенты отклика, взятые из литературных данных.
* В таких случаях возможно пропустить этап градуировки и ввести коэффициенты вручную.

### Практические рекомендации

* Градуировочные смеси должны иметь концентрации, охватывающие весь диапазон измерений.
* Для повышения точности результаты повторных измерений усредняют.
* Рекомендуется использовать многоуровневую градуировку (несколько концентрационных точек), что обеспечивает большую точность, чем одноточечная.

{% hint style="warning" %}
Использование одноточечной градуировки через начало координат допускается только при доказанной линейности детектора в исследуемом диапазоне концентраций.
{% endhint %}

## Методы расчёта количественного состава

На основе полученных градуировочных коэффициентов в ПО «NetChrom» реализуются следующие классические методы количественного расчёта:

* **Метод абсолютной градуировки (внешнего стандарта)** — концентрация компонента вычисляется напрямую по его градуировочной функции на основе полученного отклика. Требует строгой воспроизводимости объёма вводимой пробы.
* **Метод внутренней нормализации (процентного содержания)** — содержание компонента определяется как отношение его скорректированной площади (или высоты) к сумме скорректированных площадей всех пиков на хроматограмме.
* **Метод внутреннего стандарта** — в пробы добавляется известное количество фиксированного вещества (стандарта). Расчёт ведётся по отношению отклика определяемого компонента к отклику стандарта, что нивелирует ошибки ввода пробы.

### Оценка качества градуировочной кривой

Для оценки достоверности построенной зависимости в программе рассчитывается коэффициент детерминации R² (Р-квадрат):

$$R^2 = 1 - \frac{\sum (Q_{эксп} - Q_{расч})^2}{\sum (Q_{эксп} - \bar{Q})^2}$$

{% hint style="info" %}
**Критерий приемлемости:** Для линейных зависимостей качественной считается градуировка с коэффициентом детерминации R² ≥ 0,995. Если значение ниже, рекомендуется перепроверить приготовление градуировочных смесей или исключить выпадающие точки (промахи).
{% endhint %}
