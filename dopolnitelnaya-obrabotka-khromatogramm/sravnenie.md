# Сравнение

Функция **«Сравнение»** предназначена для наложения одной или нескольких хроматограмм на текущую (просматриваемую) хроматограмму.

При выполнении операции выбранные хроматограммы отображаются совместно в единой панели графиков. Начальные точки всех налагаемых хроматограмм совмещаются с началом текущей хроматограммы, что позволяет визуально сопоставить:

* времена удержания;
* высоты пиков;
* площади пиков компонентов.

## Порядок выполнения операции

1. Откройте в окне обработки базовую хроматограмму, с которой будет производиться сравнение.
2. На верхней панели инструментов нажмите кнопку **«Дополнительно»** и в раскрывшемся меню выберите пункт **«Операции с хроматограммами»**.
3. В открывшемся диалоговом окне в левом верхнем углу разверните выпадающий список **«Выберите операцию»** и установите значение **«Сравнение»**.
4. В списке доступных хроматограмм отметьте одну или несколько хроматограмм для наложения.
5. Нажмите кнопку **«Выполнить сравнение»** в правом нижнем углу окна.

## Результат обработки

После завершения обработки автоматически создается и открывается новая вкладка с совмещенным графиком всех выбранных хроматограмм.

* **Отображение сигналов:** количество выводимых сигналов в окне детекторов для каждой хроматограммы соответствует числу рабочих детекторов, указанных в методе ее регистрации.
* **Таблица пиков:** в таблице **«Пики»** отображается сводная информация по пикам со всех активных детекторов.
* **Управление каналами:** с любым из наложенных каналов можно выполнять те же действия по обработке, что и с основным, предварительно переключившись на него.
