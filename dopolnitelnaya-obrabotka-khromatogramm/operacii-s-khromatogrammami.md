# Операции с хроматограммами

В программном комплексе **NetChrom** предусмотрен инструмент **«Операции с хроматограммами».**&#x20;

Доступ к интерфейсу **«Операции с хроматограммами»** реализован через контекстное меню многофункционального инструмента **«Дополнительно»**, расположенного на верхней панели управления окна обработки хроматограмм. При нажатии на данную кнопку открывается специализированное диалоговое окно , предназначенное для выполнения математических, логических и статистических операций над зарегистрированными аналитическими сигналами.

Эти функции применяются для компенсации дрейфа изолинии, вычитания фонового шума колонки, анализа сходимости результатов, проведения контроля качества по стандартам GLP/GMP и подготовки комплексных аналитических отчетов.

## Доступные операции над сигналами

В выпадающем списке **«Выберите операцию»** оператору доступны следующие режимы обработки массивов данных:

* **Вычитание:** Коррекция базовой линии или результатов обсчета путем вычитания фонового сигнала (например, «холостого» анализа колонки или фона чистой матрицы пробы) из рабочей хроматограммы образца. Позволяет эффективно компенсировать дрейф изолинии при программировании температуры термостата колонок.
* **Сложение:** Математическое суммирование ординат (откликов) двух измерительных каналов в режиме реального времени. Используется для объединения аналитических сигналов, полученных с разных детекторов, либо для оценки суммарного отклика при параллельном детектировании.
* **Сравнение:** Интерактивное наложение и графическое сопоставление нескольких хроматограмм на одном поле. Применяется для визуальной оценки сходимости результатов серии анализов, контроля дрейфа времен удерживания или обнаружения новых примесных пиков.
* **Усреднение:** Создание результирующего сигнала на основе серии параллельных измерений одного образца. Программа вычисляет среднее арифметическое значение отклика для каждой точки по оси времени, что позволяет минимизировать случайные высокочастотные шумы детектора и значительно повысить соотношение сигнал/шум.

## Порядок выполнения математических операций

Благодаря объектной архитектуре ПО **NetChrom**, любые математические манипуляции с сигналами абсолютно безопасны для первичных данных. Исходные файлы хроматограмм остаются в системе в неизменном виде, а программа автоматически генерирует полностью новую независимую вкладку анализа.

**Для проведения обработки выполните следующие шаги:**

1. На верхней панели инструментов главного окна нажмите кнопку **Дополнительно**.
2. В открывшемся окне **«Операции с хроматограммами»** выберите требуемый тип обработки (**«Вычитание»**, **«Сложение»**, **«Сравнение»** или **«Усреднение»**).
3. Используя панель встроенного менеджера, выберите необходимые хроматограммы из списка. Для быстрого и точного отбора воспользуйтесь панелью интеллектуальной фильтрации:
   * **Временной диапазон :** Ограничивает выборку по времени регистрации файлов.
   * **Выбор прибора:** Автоматически отфильтровывает файлы по конкретному хроматографическому комплексу и его рабочей конфигурации.
   * **Выбор метода:** Отображает в таблице только те анализы, которые были выполнены по определенному рабочему методу.
   * **Теги назначения:** Позволяет мгновенно группировать и выбирать файлы по их роли в текущей сессии (например, быстрый выбор по предустановленным тегам _«Основной»_, _«Сателлит»_, <mark style="color:$danger;">«Градуировка»</mark>).
   * **Строка поиска:** Полнотекстовый динамический поиск по названию пробы, ФИО оператора или текстовому комментарию из паспорта хроматограммы.
4. <mark style="color:$danger;">Выделите целевые файлы галочками в табличной части менеджера.</mark>
5. Нажмите контекстную кнопку выполнения операции в правом нижнем углу окна (например, **«Выполнить вычитание»** ).

{% hint style="info" %}
**Автоматическое сохранение данных.** При запуске процесса будет создана новая хроматограмма с модулем детекторов _"Вычитание"_, _"Сложение"_ или _"Усреднение"_ соответственно. Исходные файлы полностью защищены от случайной перезаписи или искажения «сырых» данных.
{% endhint %}

В результате выполнения операции в текущей рабочей сессии будет автоматически создана и открыта новая вкладка хроматограммы с расчетным модулем детекторов, соответствующим выбранному типу математической обработки.

## Условия применимости операций

Для корректного математического обсчета, слияния или сопоставления сигналов и предотвращения расчетных ошибок, выбираемые хроматограммы должны строго соответствовать следующим критериям:

* Все файлы из выборки должны быть зарегистрированы на хроматографических комплексах с одинаковой конфигурацией измерительных каналов (детекторах одного типа);
* Сравниваемые сигналы должны иметь идентичную частоту передачи данных (частоту опроса АЦП) из прибора в персональный компьютер;
* Для операций _Вычитания_ и _Сложения_ рекомендуется использовать хроматограммы, снятые по одному и тому же температурному и газовому методу, во избежание физического искажения шага сетки данных.
