# Ручное редактирование хроматограммы

С помощью настройки параметров операции «Интегрирование» не всегда удается добиться автоматической корректной разметки пиков на хроматограмме. Для устранения этой проблемы прямо на графике хроматограммы можно визуально откорректировать положение характерных точек пика. Изменения выполняются интерактивно на самом графике, через контекстное меню правой кнопки мыши (ПКМ) или с помощью плавающей панели графического редактирования в правой части окна хроматограммы.

{% hint style="info" %}
Результаты ручного редактирования применяются только к текущей открытой хроматограмме и не изменяют глобальные настройки Рабочего метода.
{% endhint %}

## **Интерактивное редактирование границ пиков**

В «Netchrom 3.0» реализовано бесшовное изменение геометрии пиков, не требующее принудительного переключения специальных графических режимов на панели:

* **Перетаскивание узлов базовой линии:** Для корректировки границ достаточно нажать ЛКМ на интересующий пик для его выделения. На границах базовой линии (в точках начала и окончания пика) отобразятся интерактивные маркеры (узлы). Зажмите маркер левой кнопкой мыши и свободно перетащите его в требуемое положение на графике. Пересчет площади и высоты компонента выполнится автоматически «на лету».
* **Быстрое создание пика с клавиатуры (Alt + клики):** Для оперативной разметки пропущенного пика зажмите и удерживайте клавишу **Alt** на клавиатуре. Не отпуская её, выполните два последовательных клика ЛКМ на графике: первый — в точке предполагаемого начала пика, второй — в точке его окончания. Программа автоматически определит вершину (максимум) сигнала, построит базовую линию и внесет элемент в таблицу результатов.

**Динамическая панель графического редактирования**

Состав и доступность кнопок на плавающей панели в правой части графического поля зависят от текущего состояния выделения элементов на хроматограмме:

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (253).png" alt=""><figcaption><p>Инструменты редактирования пиков</p></figcaption></figure></div>

1. **Добавить пик** — доступно всегда. Активирует ручную разметку пика по двум точкам (начало и конец) с помощью ЛКМ.
2. **Удалить текущий пик** — _активируется только при выделении конкретного пика_. Позволяет в один клик стереть разметку выбранного компонента. Также команду удаления можно вызвать через контекстное меню ПКМ или клавишей **Delete** на клавиатуре.
3. **Разделить пик** — доступно всегда. Разделяет слившиеся пики вертикальной линией по клику ЛКМ в точку минимума (впадины) между ними.
4. **Слить пики** — _активируется только при выделении пика_. Позволяет объединить выделенный пик с соседним, полностью удаляя разделяющую их линию перпендикуляра или касательной.
5. **Групповое удаление пиков** — _полностью разблокируется только при выделении пика_. Открывает выпадающее меню:
   * _Всех пиков_ — полная очистка текущей хроматограммы от разметки.
   * _Пиков слева_ — удаление всех зарегистрированных пиков, находящихся левее (раньше по времени) текущего выделенного пика.
   * _Пиков справа_ — удаление всех зарегистрированных пиков, находящихся правее (позже по времени) текущего выделенного пика.
   * _Неидентифицированных пиков_ — быстрое удаление с графика всех пиков, для которых программа не нашла совпадений в таблице компонентов.
6. **Выбор типа пика** — _активируется только при выделении пика_. Изменяет геометрию базовой линии и математический алгоритм расчета площади.

**Геометрия разметки типов пиков**

* **Пик:** Базовая линия строится горизонтально или наклонно до уровня изолинии. Для частично слившихся компонентов программа по умолчанию опускает вертикальный перпендикуляр из точки минимума между ними до общей базовой линии. Применяется для разделенных пиков сопоставимой площади.
* **Наездник (Тангенциальное разделение):** Применяется, если малый (микропримесный) пик выходит на спадающем склоне крупного основного компонента. Базовая линия малого пика строится как касательная линия, соединяющая точку впадины с точкой завершения на изолинии. Вертикальный перпендикуляр убирается, а отсекаемая им площадь под склоном основного пика полностью исключается из расчета наездника.
* **Хвостатый:** Визуальное отображение и геометрия разметки по касательной полностью аналогичны типу «Наездник». Данный статус используется в случаях, когда предыдущий крупный компонент имеет сильно затянутый асимметричный задний фронт («хвост»), перетекающий в подножие следующего пика, чтобы исключить влияние этого шлейфа на результаты измерения примеси.
* **Базовый пик (Разделение по долинам):** Применяется для изменения алгоритма разделения группы слившихся пиков. Программа автоматически удаляет вертикальный перпендикуляр, опущенный к общей изолинии, и строит индивидуальные базовые линии для каждого компонента в группе непосредственно через общую точку впадины (долины) между ними.

## Cоздание событий интегрирования

Новая функция ПО позволяет визуально размечать временные события обработки прямо на текущей хроматограмме без ручного внесения данных в таблицы Рабочего метода. Для этого используется команда ПКМ -> **«Создать событие»**.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (254).png" alt=""><figcaption><p>Событие интегрирования</p></figcaption></figure></div>

**Порядок разметки события на графике:**

1. Нажмите ПКМ в окне хроматограммы, перейдите в меню **«Создать событие»** и выберите необходимый тип правила (например, _«Запретить разметку пиков»_).
2. На временной шкале графика (верхняя панель) появятся графические маркеры в виде **фиолетовых ромбов**, обозначающие границы действия созданного события.
3. Программа автоматически внесет новую строку в таблицу на вкладке **«Интегрирование»** в нижней части экрана, зафиксировав время начала и окончания интервала.
4. Корректировка временного интервала возможна двумя способами:
   * _Графически:_ Перетаскивая фиолетовые ромбы-маркеры влево или вправо по шкале времени с помощью мыши.
   * _Таблично:_ Вручную отредактировав значения в колонках _«Начало (мин)»_ и _«Конец (мин.)»_ непосредственно во вкладке **«Интегрирование»**.

**Отмена ручных правок**

Для полного сброса всех внесенных графических изменений и возврата к автоматическому расчету выполните **«Обработку по рабочему методу»**. Программа сотрет ручную графическую разметку, удалит созданные на графике локальные события и заново рассчитает хроматограмму строго по исходным параметрам Рабочего метода.
