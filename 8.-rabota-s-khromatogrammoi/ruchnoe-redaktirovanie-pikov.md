# 👹 Ручное редактирование пиков

С помощью настройки параметров операции «Интегрирование» не всегда удается добиться автоматической корректной разметки пиков на хроматограмме. Для устранения этой проблемы прямо на графике хроматограммы можно визуально откорректировать положение характерных точек пика. Изменения выполняются интерактивно на самом графике, через контекстное меню правой кнопки мыши (ПКМ) или с помощью плавающей панели графического редактирования в правой части окна хроматограммы.

{% hint style="info" %}
Результаты ручного редактирования применяются только к текущей открытой хроматограмме и не изменяют глобальные настройки Рабочего метода.
{% endhint %}

В «Netchrom 3.0» реализовано бесшовное изменение геометрии пиков, не требующее принудительного переключения специальных графических режимов на панели:

* **Перетаскивание узлов базовой линии:** Для корректировки границ достаточно нажать ЛКМ на интересующий пик для его выделения. На границах базовой линии (в точках начала и окончания пика) отобразятся интерактивные маркеры (узлы). Зажмите маркер левой кнопкой мыши и свободно перетащите его в требуемое положение на графике. Пересчет площади и высоты компонента выполнится автоматически «на лету».
* **Быстрое создание пика с клавиатуры (Alt + клики):** Для оперативной разметки пропущенного пика зажмите и удерживайте клавишу **Alt** на клавиатуре. Не отпуская её, выполните два последовательных клика ЛКМ на графике: первый — в точке предполагаемого начала пика, второй — в точке его окончания. Программа автоматически определит вершину (максимум) сигнала, построит базовую линию и внесет элемент в таблицу результатов.

**Динамическая панель графического редактирования**

Состав и доступность кнопок на плавающей панели в правой части графического поля зависят от текущего состояния выделения элементов на хроматограмме:

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (253).png" alt=""><figcaption><p>Инструменты редактирования пиков</p></figcaption></figure></div>

1. **Добавить пик** — доступно всегда. Активирует ручную разметку пика по двум точкам (начало и конец) с помощью ЛКМ.
2. **Удалить текущий пик** — _активируется только при выделении конкретного пика_. Позволяет в один клик стереть разметку выбранного компонента. Также команду удаления можно вызвать через контекстное меню ПКМ или клавишей **Delete** на клавиатуре.
3. **Разделить пик** — доступно всегда. Разделяет слившиеся пики вертикальной линией по клику ЛКМ в точку минимума (впадины) между ними.
4. **Слить пики** — _активируется только при выделении пика_. Позволяет объединить выделенный пик с соседним, полностью удаляя разделяющую их линию перпендикуляра или касательной.
5. **Групповое удаление пиков** — _полностью разблокируется только при выделении пика_. Открывает выпадающее меню:
   * _Всех пиков_ — полная очистка текущей хроматограммы от разметки.
   * _Пиков слева_ — удаление всех зарегистрированных пиков, находящихся левее (раньше по времени) текущего выделенного пика.
   * _Пиков справа_ — удаление всех зарегистрированных пиков, находящихся правее (позже по времени) текущего выделенного пика.
   * _Неидентифицированных пиков_ — быстрое удаление с графика всех пиков, для которых программа не нашла совпадений в таблице компонентов.
6. **Выбор типа пика** — _активируется только при выделении пика_. Изменяет геометрию базовой линии и математический алгоритм расчета площади.

**Геометрия разметки типов пиков**

* **Пик:** Базовая линия строится горизонтально или наклонно до уровня изолинии. Для частично слившихся компонентов программа по умолчанию опускает вертикальный перпендикуляр из точки минимума между ними до общей базовой линии. Применяется для разделенных пиков сопоставимой площади.
* **Наездник (Тангенциальное разделение):** Применяется, если малый (микропримесный) пик выходит на спадающем склоне крупного основного компонента. Базовая линия малого пика строится как касательная линия, соединяющая точку впадины с точкой завершения на изолинии. Вертикальный перпендикуляр убирается, а отсекаемая им площадь под склоном основного пика полностью исключается из расчета наездника.
* **Хвостатый:** Визуальное отображение и геометрия разметки по касательной полностью аналогичны типу «Наездник». Данный статус используется в случаях, когда предыдущий крупный компонент имеет сильно затянутый асимметричный задний фронт («хвост»), перетекающий в подножие следующего пика, чтобы исключить влияние этого шлейфа на результаты измерения примеси.
* **Базовый пик (Разделение по долинам):** Применяется для изменения алгоритма разделения группы слившихся пиков. Программа автоматически удаляет вертикальный перпендикуляр, опущенный к общей изолинии, и строит индивидуальные базовые линии для каждого компонента в группе непосредственно через общую точку впадины (долины) между ними.

## Масштабирование

Для детального рассмотрения формы пиков, прецизионного контроля положения маркеров базовой линии и анализа микропримесей в программном комплексе реализован механизм интерактивного графического масштабирования.

Для того чтобы приблизить конкретную группу пиков или проанализировать поведение нулевой линии на локальном промежутке времени, выполните следующие действия:

1. Наведите курсор мыши в поле хроматограммы к предполагаемому верхнему левому углу целевой зоны.
2. Зажмите левую кнопку мыши (**ЛКМ**) и, не отпуская её, протяните курсор по диагонали вправо и вниз.
3. На экране отобразится динамическая синяя прямоугольная рамка, ограничивающая область будущего увеличения.
4. Отпустите **ЛКМ**.

Программа мгновенно пересчитает оси времени (X) и напряжения (Y), растянув выделенный рамкой фрагмент на всю полезную площадь графического окна.

{% hint style="info" %}
Интерактивное масштабирование хроматограммы на экране является исключительно функцией визуального отображения интерфейса. Изменение масштаба графика не влияет на математический расчет площадей пиков, не изменяет метаданные и не перестраивает таблицу результатов.
{% endhint %}

**Возврат к исходному масштабу (Сброс увеличения)**

Если необходимо отменить приближение и вернуть хроматограмму к отображению на весь экран (отобразить полный цикл анализа от `00:00` до конца регистрации):

* **Способ А (Через контекстное меню):** Нажмите правую кнопку мыши (**ПКМ**) в любой точке графика и в открывшемся меню выберите команду **«На весь экран»**.
* **Способ Б (Горячие клавиши):** Используйте стандартную быструю комбинацию клавиш **Ctrl + A** на клавиатуре.

## Навигация внутри увеличенного участка

При детальном рассмотрении хроматограммы в режиме приближения оператор может перемещать рабочую область вдоль осей без сброса масштаба:

* **Панорамирование мышью (Инструмент «Рука»):** Зажмите и удерживайте клавишу **Shift** на клавиатуре. Не отпуская её, нажмите **ЛКМ** в любом месте графика и, удерживая кнопку нажатой, свободно перемещайте мышь. Хроматограмма будет плавно двигаться вслед за курсором в любом направлении (как по оси времени X, так и по оси сигнала Y).
* **Прокрутка по времени:** Для перемещения графика влево или вправо используйте горизонтальную полосу прокрутки (скроллбар) под осью времени.
* **Масштабирование колесом мыши:** Прокрутка колеса мыши вверх/вниз в поле графика позволяет осуществлять плавное пошаговое приближение или удаление сигнала относительно текущего положения курсора.

## Удаление разметки

В процессе интерактивной работы с хроматограммой может потребоваться полностью или частично сбросить текущие результаты автоматического интегрирования, чтобы выполнить разметку заново вручную. Для этого используется кнопка **«Групповое удаление пиков»** на правой плавающей панели.

**Пошаговый алгоритм полного удаления всей разметки с графика:**

Для того чтобы полностью очистить хроматограмму от результатов обсчета:

1. Наведите курсор на правую плавающую панель и нажмите кнопку **\[Удаление пиков]**.
2. В открывшемся выпадающем меню выберите команду **«Всех пиков»**.

**Визуальный результат:** мгновенно удаляет все синие маркеры и полностью стирает базовую линию на всем протяжении хроматограммы. Исходный физический сигнал детектора остается без изменений, а таблица результатов полностью очищается.

**Выборочное групповое удаление**

Если вам необходимо очистить не всю хроматограмму, а только её конкретную часть, необходимо использовать метод выделения опорного пика:

1. Кликните левой кнопкой мыши (**ЛКМ**) по любому размеченному пику на графике, который послужит границей раздела.
2. Откройте выпадающее меню кнопки **\[Удаление пиков]** на правой панели.
3. В зависимости от аналитической задачи выберите специализированную команду:
   * **Удалить текущий пик** — этот пункт появляется в меню _только при выделении пика_. Позволяет стереть разметку одного конкретного выбранного компонента.
   * **Пиков слева** — команда мгновенно удаляет разметку всех компонентов, находящихся левее (раньше по времени) текущего выделенного пика. Идеально подходит для быстрой очистки стартового участка хроматограммы.
   * **Пиков справа** — команда стирает разметку всех компонентов, находящихся правее (позже по времени) выделенного пика. Применяется для моментальной очистки протяженных участков шума в конце анализа.
   * **Неидентифицированных пиков** — важнейшая сервисная функция, позволяющая в один клик очистить хроматограмму от фонового шума. Программа проанализирует график и удалит разметку только тех пиков, для которых не было найдено совпадений по времени удерживания в _Редакторе компонентов_ текущего метода. Все целевые (идентифицированные и подписанные) газы гарантированно останутся на графике.

## Создание пиков

Если автоматический алгоритм интегрирования пропустил целевой компонент из-за завышенных глобальных порогов фильтрации шума или специфической геометрии нулевой линии, оператор может разметить его на графике вручную двумя способами.

**Использование горячих клавиш (Комбинация Alt + ЛКМ)**

1. Зажмите и удерживайте клавишу **Alt** на клавиатуре.
2. Не отпуская её, выполните два последовательных клика левой кнопкой мыши (**ЛКМ**) на графике хроматограммы:
   * _Первый клик_ — в точке предполагаемого начала основания пика;
   * _Второй клик_ — в точке его предполагаемого окончания.

**Использование интерактивного контекстного меню**

1. Наведите курсор мыши на область неразмеченного компонента и нажмите правую кнопку мыши (**ПКМ**).
2. В открывшемся списке команд выберите пункт **«Добавить пик»** (иконка со знаком плюс `+`). Программа перейдет в режим графической разметки по двум точкам.
3. Наведите изменившийся курсор на **точку начала основания пика** и совершите один клик **ЛКМ**.
4. Переместите курсор на **точку окончания основания пика** и совершите второй клик **ЛКМ**.

Сразу после фиксации границ пика любым из способов выполняются следующие математические и графические операции:

* **Поиск максимума:** Программа сканирует массив данных сигнала между двумя указанными точками, находит точную вершину (максимум) пика и отмечает её вертикальной осевой линией с подписью времени удерживания.
* **Построение геометрии:** Программа проводит под пиком локальный отрезок базовой линии и расставляет интерактивные маркеры-узлы (черные точки) на его границах.
* **Обновление отчетов:** Измеренная высота и рассчитанная площадь нового компонента заносятся во вкладку результатов _«Пики»_.

## Редактирование границ пика

После того как пик успешно создан вручную, можно настроить его геометрические границы непосредственно на графике хроматограммы.

1. Кликните левой кнопкой мыши (**ЛКМ**) по интересующему пику для его выделения.
2. После активации компонента на границах его базовой линии отобразятся интерактивные маркеры в виде **серых круглых точек**.
3. Зажмите **ЛКМ** нужную серую точку начала или окончания основания пика и свободно переместите её вдоль оси времени. Локальная розовая нулевая линия мгновенно перерисуется под новым углом.
4. При необходимости скорректируйте положение вершины асимметричного компонента, передвинув мышью вертикальный осевой маркер максимума.

{% hint style="info" %}
Математический пересчет высоты, площади и процентного содержания компонента выполняется программным комплексом автоматически в момент отпускания левой кнопки мыши.
{% endhint %}

## Автоматическая разметка компонентов

Как только ручной пик зафиксирован на хроматограмме, запускается алгоритм идентификации в фоновом режиме:

* Программа считывает полученное время удерживания вершины и сопоставляет его с временными окнами (допусками), заданными в _Компонентах_ текущего метода.
* Если в методе присутствуеткомпонент, выходящий в этот временной интервал, программа автоматически присваивает пику его наименование.

## Ручной выбор компонента

В случаях, когда после ручной или автоматической разметки пик на хроматограмме остался неидентифицированным, можно выполнить принудительную ручную привязку имени газа через таблицу результатов.

1. В нижней части рабочего пространства перейдите на вкладку результатов **«Пики»**.
2. Найдите в таблице строку, соответствующую интересующему вас пику. Если предварительно выбрать необходимый пик, его строка будет подсвечена в итоговой таблице.
3. Нажмите левой кнопкой мыши (**ЛКМ**) в ячейку столбца **«Компонент»** для этой строки. В ячейке откроется выпадающий список со справочником всех компонентов, зарегистрированных в текущем методе.
4. Выберите из списка целевое наименование компонента.

**Результат операции**

* **В таблице результатов:** В строке пика фиксируется выбранное имя компонента.
* **На графике хроматограммы:** Надпись над вершиной пика обновляется и принимает правильный метрологический вид: **\[Время удерживания], \[Имя компонента]**.
* Поле графика вокруг пика подсвечивается, наглядно демонстрирующим границы временного окна идентификации для данного газа.

{% hint style="info" %}
Если вам необходимо отменить ручную привязку и снова сделать пик неидентифицированным, повторно откройте этот выпадающий список в таблице и выберите самую верхнюю строку — **«Нет компонента»**.
{% endhint %}
