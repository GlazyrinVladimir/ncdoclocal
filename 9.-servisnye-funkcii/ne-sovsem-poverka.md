# Поверка

Программа обеспечивает автоматический расчет метрологических параметров базовой линии детектора — уровня флуктуационных шумов, кратковременного и долговременного дрейфа за часовой интервал, а также контроль предела допускаемых отклонений и вычисление пределов обнаружения. Полученные параметры используются для проведения периодической поверки прибора, оценки стабильности работы хроматографической системы и определения пригодности оборудования к выполнению аналитических измерений.

Запуск специализированного модуля оценки стабильности базовой линии осуществляется непосредственно из главного окна обработки хроматограмм ПО «NetChrom»:

1. На верхней панели инструментов найти группу управляющих элементов и нажать кнопку **«Поверка»**.
2. В раскрывшемся выпадающем меню выбрать команду **«Шум/дрейф/предел»**.
3. После активации команды на экране отобразится диалоговое окно **«Расчет шума, дрейфа и предела»** для выбранной хроматограммы.

## Интерфейс и элементы управления окна расчета

Диалоговое окно содержит следующие функциональные области:

* **Вкладки выбора каналов (детекторов)** — расположены в верхней части окна (например, **«ПФД-1»**, **«ПИД-1»**, **«ДТП-1»**). Обеспечивают переключение между зарегистрированными физическими каналами измерения.

* **Панель «Анализ»** — содержит информационные поля результатов автоматического измерения текущей хроматограммы:
  * **Шум детектора (мВ)** — амплитуда высокочастотных флуктуаций信号 в милливольтах.
  * **Дрейф (мВ/мин)** — скорость однонаправленного изменения базовой линии в минуту.
  * **Флукт. шум (а)** — уровень флуктуационного шума, приведенный к абсолютным единицам тока или соответствующей физической величине детектора в экспоненциальном формате.
  * **Дрейф (а/ч)** — долговременный дрейф нулевого сигнала, пересчитанный за часовой интервал в абсолютных единицах.
  * **Предел (г/с)** — расчетная величина предела обнаружения (минимально детектируемого количества) компонента в граммах в секунду.
* **Панель «Расчет»** — содержит редактируемые поля для задания исходных метрологических данных. Состав полей динамически изменяется в зависимости от выбранного типа детектора и положения тумблеров режимов.

## Расчет для различных типов детекторов

В зависимости от физического типа детектора, выбранного во вкладках, структура панели ввода данных адаптируется под специфику конкретного канала измерения.

**Режим работы с пламенно-ионизационным детектором (ПИД)**

При выборе вкладки **«ПИД»** и переводе тумблера **«По пропану»** в положение **«Вкл.»** интерфейс панели ввода динамически перестраивается. Поле прямой массовой концентрации скрывается, а система запрашивает физико-химические параметры газовой смеси для автоматического приведения объема к нормальным условиям:

* **Коэффициент** — редактируемое поле для ввода массовой доли определяемого элемента в молекуле контрольного компонента смеси (см. справочные значения коэффициентов ниже).
* **По пропану** — двухпозиционный переключатель, переведенный в активное состояние (**«Вкл.»**).
* **Молек. масса** — поле для ввода молярной массы контролируемого углеводорода (г/моль).
* **Объемная доля (%)** — поле для ввода паспортного значения объемной доли компонента в поверочной газовой смеси (ПГС).
* **Атм. давление (Па)** — поле для ввода текущего атмосферного давления в лаборатории в паскалях.
* **Температура (°C)** — поле для ввода фактической температуры окружающего воздуха в градусах Цельсия.

**Режим работы с детектором по теплопроводности (ДТП)**

При работе с катарометром (**«ДТП»**) чувствительность детектора напрямую зависит от объемной скорости потока. При переводе тумблера **«По пропану»** в положение **«Вкл.»** интерфейс панели объединяет гидродинамические и физико-химические характеристики газовой смеси:

* **Коэффициент** — редактируемое поле для ввода масштабирующего множителя.
* **Расход (мл/мин)** — специализированное поле для ввода фактического расхода газа-носителя через измерительную ячейку ДТП.
* **По пропану** — двухпозиционный переключатель, переведенный в активное состояние (**«Вкл.»**).
* Параметры **«Молек. масса»**, **«Объемная доля (%)»**, **«Атм. давление (Па)»**, **«Температура (°C)»** — стандартные поля ввода характеристик газа и окружающей среды.

{% hint style="info" %}
При переводе всех тумблеров в положение **«Откл.»** для ПИД и ДТП активируется режим прямого расчета по массовой концентрации контрольного компонента. В этом случае на панели отображается единственное базовое поле **«Сн (мг/мл)»**.
{% endhint %}

**Режим работы с пламенно-фотометрическим детектором (ПФД)**

При выборе вкладки **«ПФД»** и переводе тумблера **«По сероводороду»** в положение **«Вкл.»** поле прямой массовой концентрации скрывается, а система запрашивает физико-химические параметры газовой смеси для автоматического приведения объема к нормальным условиям:

* **Коэффициент** — редактируемое поле для ввода масштабирующего множителя (по умолчанию `0`).
* **По сероводороду** — двухпозиционный переключатель, переведенный в активное состояние (**«Вкл.»**).
* **Молек. масса** — поле для ввода молярной массы целевого серосодержащего компонента (г/моль).
* **Объемная доля (%)** — поле для ввода паспортного значения объемной доли контролируемого компонента в поверочной газовой смеси (ПГС).
* **Атм. давление (Па)** — поле для ввода текущего атмосферного давления в лаборатории в паскалях.
* **Температура (°C)** — поле для ввода фактической температуры окружающего воздуха в градусах Цельсия.

**Справочные значения поправочного коэффициента (К)**

Поле **«Коэффициент»** предназначено для ввода массовой доли определяемого элемента (углерода, фосфора или серы) в молекуле контрольного компонента смеси. Программа использует данный множитель для приведения аналитического сигнала к чистому элементу при расчете предела обнаружения.

При отсутствии специфических требований методики значение коэффициента по умолчанию принимается равным `1`. При проведении государственной поверки или калибровки прибора с использованием сертифицированных контрольных смесей в поле вносится одно из следующих регламентированных значений:

* **К = 1** — базовое значение для всех типов детекторов (прямой расчет без пересчета на элемент);
* **К = 0.84** — ПИД: Контрольная смесь гептан в октане, нонане;
* **К = 0.82** — ПИД: Контрольная смесь пропан в гелии или азоте;
* **К = 0.75** — ГИД: Контрольная смесь метан в гелии;
* **К = 0.118** — ТИД, ПФД по фосфору: Контрольная смесь метафос в гексане;
* **К = 0.112** — ТИД, ПФД по фосфору: Контрольная смесь фенитротион в гексане;
* **К = 0.112** — ПФД по сере: Контрольная смесь метафос в гексане;
* **К = 0.115** — ПФД по сере: Контрольная смесь фенитротион в гексане;
* **К = 0.941** — ПФД по сере: Контрольная смесь сероводорода в гелии или азоте.

{% hint style="info" %}
Окно программы предоставляет встроенный интерактивный список для автоматического выбора и вставки указанных коэффициентов. Оператору достаточно выбрать нужную строку из выпадающего меню, после чего числовое значение автоматически занесется в расчетную матрицу метода.
{% endhint %}

## Общий математический алгоритм расчета параметров

Программа обрабатывает выделенный массив данных хроматограммы по следующим критериям:

1. **Дрейф нулевого сигнала за час:** систематическое однонаправленное изменение положения базовой линии. Тренд аппроксимируется методом линейной регрессии с автоматическим пересчетом к стандартизированному значению за 1 час:

$$\text{Дрейф}_{\text{час}} = \frac{y_2 - y_1}{x_2 - x_1} \cdot 60$$

где y<sub>1</sub>, y<sub>2</sub> — начальное и конечное значения сигнала тренда, а x<sub>1</sub>, x<sub>2</sub> — временные границы интервала в минутах.

2. **Приведение объема газовой пробы к нормальным условиям** (при активных тумблерах «Вкл.»):

$$V_0 = V_{\text{дозы}} \cdot \frac{P \cdot 273.15}{101325 \cdot (273.15 + t)}$$

где V<sub>дозы</sub> — объем дозировочной петли, P — введенное «Атм. давление (Па)», t — введенная «Температура (°C)». На основе вычисленного объема V<sub>0</sub>, заданной молярной массы и объемной доли система рассчитывает абсолютную массу вещества, прошедшую через измерительную ячейку.

3. **Вычисление предела обнаружения (г/с):** итоговое значение минимально детектируемого потока вещества выводится в поле **«Предел (г/с)»** панели **«Анализ»**. Расчет производится путем сопоставления массы контрольного компонента с мгновенным значением из поля **«Флукт. шум (а)»** и эффективной шириной хроматографического пика. При расчете для ДТП в математическую модель также закладывается значение из поля **«Расход (мл/мин)»**.
