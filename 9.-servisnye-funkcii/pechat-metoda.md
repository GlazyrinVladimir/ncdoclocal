# Печать метода

Функция предназначена для формирования и вывода на печать (или экспорта) отчета, содержащего аппаратные настройки хроматографа «Кристаллюкс-4000М», параметры обработки и градуировочные данные.

Программа позволяет распечатать два типа методов:

* **Рабочий метод** — текущий активный метод, по которому выполняются текущие измерения.
* **Метод хроматограммы** — архивный метод, сохраненный непосредственно внутри файла зарегистрированной хроматограммы.

**Порядок формирования отчета по методу**

* Откройте интересующий метод.
* На Панели управления выберите команду **«Печать метода»**. Откроется одноименное диалоговое окно.
* В левой панели **«Содержание метода»** установите флаги напротив тех групп параметров, которые необходимо включить в итоговый отчет:
  * Группа **«Управление»**:
    * **«Параметры управления»** — общие системные настройки;
    * **«Температуры»** и **«Программирование температур»** — режимы термостата колонок;
    * **«Расход газов и давление»**, **«Программирование давления»** — настройки пневматической системы;
    * Специальные режимы: **«Режим продувки»**, **«Режим экономии»**, **«Режим сплит»**;
    * Алгоритмы: **«Параметры обработки»**, **«Параметры расчета»**.
  * Группа **«Компоненты»**:
    * **«Свойства компонента»** и **«Градуировочные коэффициенты»** — идентификационные данные пиков;
    * Визуальные данные: **«Градуировочный график»**, **«Градуировочные точки»**.
* При установке или снятии флагов содержимое в правой панели **«Предпросмотр отчета»** обновляется автоматически в режиме реального времени.
* Для отправки сформированного отчета на принтер нажмите кнопку **«Распечатать отчет»**, расположенную в левом нижнем углу окна.
* Для закрытия окна без печати нажмите кнопку **«Отмена»**.

{% hint style="info" %}
В шапке бланка предпросмотра автоматически генерируются метаданные: название метода, название хроматографа, модель прибора (Кристаллюкс-4000М), модуль детекторов, а также текущая дата и время формирования отчета. В правом верхнем углу отображается сквозная нумерация страниц.
{% endhint %}
