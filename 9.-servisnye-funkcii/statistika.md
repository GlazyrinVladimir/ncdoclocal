# Статистика

Функция предназначена для автоматического расчета статистических характеристик по серии хроматограмм. Модуль позволяет вычислять средние значения, абсолютные и относительные среднеквадратичные отклонения (СКО) для времен удерживания, площадей, высот пиков или рассчитанных концентраций компонентов.

**Порядок вызова функции**

* Перейдите в окно открытой хроматограммы.
* На верхней панели инструментов нажмите кнопку **«Дополнительно»**.
* В выпадающем меню выберите пункт **«Статистика»**.

{% hint style="warning" %}
Окно статистической обработки всегда открывается для **активного хроматографа** (его наименование и текущий статус отображаются в правом верхнем углу интерфейса программы).

Расчет будет производиться по базе данных активного прибора, даже если в этот момент на экране открыта и просматривается хроматограмма, зарегистрированная на другом хроматографе. Перед запуском расчетов обязательно убедитесь, что выбран правильный прибор!
{% endhint %}

## Порядок работы

После вызова функции на экране появится диалоговое окно «Статистика». Расчет и вывод метрологических характеристик выполняются в строго определенной последовательности:

* **1. Выберите метод** — в левом верхнем блоке нажмите на выпадающий список и выберите расчетный метод, по которому производилась обработка анализов.

{% hint style="warning" %}
В выпадающем списке отображаются только те методы обработки, которые привязаны к **активному хроматографу**. Найти в этом перечне методы других приборов невозможно.
{% endhint %}

* **2. Выберите компонент** — в центральном верхнем блоке откройте выпадающий список. В нем отобразится перечень веществ (пиков), идентифицированных в выбранном методе. Укажите конкретный целевой компонент, по которому требуется провести статистическую обработку.
* **3. Выберите параметр расчета** — в правом верхнем блоке выберите из выпадающего списка физическую величину или расчетный показатель для проведения математического анализа:
  * **«Площадь»** — для анализа площадей пиков;
  * **«Высота»** — для проверки стабильности амплитуды пика;
  * **«Время удерживания»** — для оценки воспроизводимости качественной идентификации компонента;
  * **«Концентрация 1»**, **«Концентрация 2»**, **«Концентрация 3»** — для расчета погрешности и сходимости результатов по различным типам (вариантам) расчета количественного содержания, настроенным в методе.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (349).png" alt=""><figcaption><p>Доступные параметры расчёта</p></figcaption></figure></div>

* **4. Выберите хроматограммы для расчета** — в центральной панели отобразится табличный журнал зарегистрированных анализов за выбранный интервал времени (например, _«За все время»_). Установите флаги напротив тех хроматограмм, которые необходимо объединить в статистическую выборку для обсчета.

{% hint style="info" %}
В табличном журнале отображаются только те хроматограммы, которые были обработаны по выбранному на первом шаге методе. Если список пуст, это означает, что в базе данных отсутствуют файлы анализов, соответствующие выбранному методу активного хроматографа.
{% endhint %}

## Анализ полученных результатов

Как только файлы хроматограмм будут выбраны, система автоматически выполнит математическую обработку и заполнит нижние информационные блоки в режиме реального времени:

* Блок **«Исходные данные»** — выводит порядковые номера и названия выбранных файлов хроматограмм с указанием конкретного численного значения анализируемого параметра (времени, площади, высоты или концентрации) для каждого анализа.
* Блок **«Результат расчета»** — формирует итоговую метрологическую таблицу, содержащую следующие рассчитанные параметры:
  * **«Доверительная вероятность»** — установленный по умолчанию уровень статистической значимости;
  * **«Объем выборки»** — общее количество хроматограмм, включенных в расчет;
  * **«Выборочное среднее»** — среднее арифметическое значение измеряемой величины;
  * **«Выборочная дисперсия»** — мера рассеяния данных вокруг среднего значения;
  * **«СКО»** — абсолютное среднеквадратичное отклонение;
  * **«Относительное СКО»** — коэффициент вариации (воспроизводимости);
  * **«Оценка СКО»** — смещенная или несмещенная оценка стандартного отклонения;
  * **«Доверительный интервал»** — границы погрешности измерений;
  * **«Число аномальных результатов»** — количество пиков, автоматически отброшенных системой как грубые промахи (выбросы) на основании статистических критериев.

**Автоматическая отбраковка аномальных результатов**

В модуле «Статистика» реализован алгоритм автоматического выявления и исключения грубых погрешностей (выбросов) из общего расчета.

Если в выбранной серии хроматограмм присутствует анализ, значение которого резко отличается от остальных (например, из-за ошибки ввода пробы или технического сбоя), система фиксирует его как промах:

* В поле **«Число аномальных результатов»** отображается количество обнаруженных выбросов.
* Обнаруженное аномальное значение автоматически исключается из расчета метрологических характеристик. Итоговые показатели выборки (Выборочное среднее, СКО, Относительное СКО и др.) пересчитываются только по оставшимся достоверным анализам.

{% hint style="warning" %}
При появлении аномальных результатов перейдите в блок **«Исходные данные»** и сравните численные значения в колонке **«Значение»**. Файл с критически заниженным или завышенным показателем рекомендуется исключить из серии ручным снятием флага в таблице выбора хроматограмм, после чего повторить проверку.
{% endhint %}
