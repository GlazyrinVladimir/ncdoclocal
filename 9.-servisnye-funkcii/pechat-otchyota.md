# Печать отчёта

Функция предназначена для конструирования, редактирования и вывода на печать индивидуальных отчетов по выбранному файлу хроматограммы на основе гибких настраиваемых шаблонов.

Вызов окна осуществляется через Панель инструментов  — **«Печать»** (на панели инструментов открытой хроматограммы). При этом открывается отдельное рабочее пространство **«Редактор отчетов»**.

Рабочая область окна состоит из трех основных элементов:

* **Левая панель инструментов** — кнопки для управления структурой документа, масштабом отображения и выводом на печать.
* **Центральная панель «Предпросмотр отчета»** — интерактивное поле отображения бланка, где в реальном времени формируется итоговый внешний вид документа.
* **Правая панель «Параметры документа»** — конфигурационный блок, в котором выбираются исходные файлы данных, шаблоны, а также настраиваются параметры конкретных информационных блоков.

## **Меню управления файлом шаблона и отчета**

Основные операции по работе с конфигурационными файлами и готовыми документами сгруппированы в главном меню **«Файл»** окна «Редактор отчетов». Доступ к ключевым функциям также дублируется стандартными комбинациями горячих клавиш:

* **«Открыть шаблон» (Ctrl + O)** — открывает диалоговое окно для поиска и загрузки ранее созданного файла шаблона отчета.
* **«Сохранить шаблон» (Ctrl + S)** — перезаписывает текущие изменения в структуре блоков и оформлении непосредственно в открытый файл шаблона.
* **«Сохранить как...»** — позволяет записать текущую конфигурацию расположения информационных блоков в виде нового файла шаблона с возможностью вручную указать директорию и имя.
* **«Печать» (Ctrl + P)** — открывает системное диалоговое окно выбора принтера для вывода сформированного бланка из области предпросмотра.
* **«Экспорт отчета» (Ctrl + E)** — преобразует текущий документ со всеми графиками и таблицами во внешние форматы данных для хранения или последующей сторонней обработки.

## **Порядок формирования отчета хроматограммы**

* В правой панели в блоке **«Файл хроматограммы»** выберите хроматограмму, данные которой необходимо внести в отчет. По умолчанию подгружается текущий активный файл.
* В блоке **«Шаблон отчета»** нажмите кнопку выбора файла и укажите ранее сохраненный файл шаблона. Если шаблон не выбран, отчет формируется с чистого листа (отображается только пустой заголовок).
* Для конструирования структуры отчета используйте кнопки на левой панели:
  * **«Добавить блок»** — открывает меню выбора информационных блоков;
  * **«Удалить блок»** — исключает выделенный элемент из структуры документа. Для удаления блока предварительно кликните на него левой кнопкой мыши прямо в области предпросмотра отчета, после чего нажмите эту кнопку на левой панели инструментов.
  * **«Отменить действие»** — откатывает последнее внесенное изменение.
* Для изменения отображения бланка в окне предпросмотра используйте кнопки **«Увеличить масштаб»** и **«Уменьшить масштаб»**.
* При необходимости сохранить измененную структуру отчета как новый образец нажмите кнопку **«Сохранить шаблон»**.
* Для вывода готового документа на бумажный носитель или в PDF-принтер нажмите кнопку **«Печать отчета»**.

## **Добавление информационных блоков в отчет**

Переход к меню добавления разделов осуществляется через пункт главного меню **«Редактирование»** — **«Добавить новый раздел»** или с помощью кнопки **«Добавить блок»** на левой панели инструментов.

Выбор любого из пунктов интегрирует соответствующий модуль данных в область предпросмотра отчета:

* **«Паспорт»** — добавляет блок с общими регистрационными данными анализа (название организации, ФИО оператора, номер прибора, дата и время проведения измерения).
* **«Параметры управления»** — включает в отчет детальные аппаратные настройки хроматографа «Кристаллюкс-4000М», включая температурные режимы зон и параметры работы детекторов.
* **«Параметры пробы»** — выводит информацию о введенном образце (название пробы, объем ввода, метод дозирования, имя оператора).
* **«Параметры колонки»** — отображает технические характеристики используемой хроматографической колонки (тип, длина, внутренний диаметр, фаза, заводской номер).
* **«Параметры обработки»** — добавляет сведения о математических алгоритмах и критериях, примененных при первичном обсчете хроматограммы.
* **«События интегрирования»** — формирует таблицу временных интервалов и команд разметки пиков (фиксация изолинии, принудительное разделение, отсечка шумов).
* **«Хроматограмма»** — вставляет графическое изображение хроматографического графика с возможностью отображения разметки пиков и названий компонентов.
* **«Пики»** — генерирует классическую таблицу результатов по всем обнаруженным пикам (время удерживания, площадь, высота, ширина, асимметрия).
* **«Компоненты»** — выводит таблицу идентифицированных целевых веществ с рассчитанными значениями концентраций на основании градуировочных данных.
* **«Группы»** — добавляет суммарную таблицу по заранее объединенным группам пиков со сложным или многокомпонентным расчетом.

## **Настройка параметров информационных блоков**

При выделении некоторых интегрированных блоков в области предпросмотра, в правой панели **«Параметры документа»** автоматически отображаются контекстные инструменты для их локального конфигурирования.

**Настройка блока «Пики» («Компоненты»)**

Блок позволяет гибко управлять отображением данных с различных измерительных каналов хроматографа «Кристаллюкс-4000М».

* В правой части окна появляется список всех задействованных в анализе детекторов (например, **«ПИД-1»**, **«ДТП-1»**, **«ДТП-2»**).
* С помощью интерактивных переключателей (тумблеров) оператор может активировать или деактивировать вывод табличных данных для каждого конкретного детектора. При отключении переключателя соответствующая таблица пиков мгновенно скрывается из бланка предпросмотра.

**Настройка блока «Хроматограмма»**

Для графического модуля предусмотрены параметры геометрического позиционирования и ориентации графиков на печатной странице:

* **«Высота (см)»** — текстовое поле ввода, в котором задаются точные физические размеры графического поля хроматограммы по вертикали при выводе на печать (например, _20,7 см_). При изменении значения масштаб графика в окне предпросмотра пересчитывается автоматически.
* **«Альбомная ориентация»** — переключатель режима разворота страницы для данного блока. Позволяет развернуть хроматограмму по горизонтали для более детального изучения длинных последовательностей пиков или многокомпонентных смесей без изменения ориентации всего остального текстового документа.

{% hint style="info" %}
В базовой шапке отчета NetChrom 3.0 автоматически центрирует метаданные: имя файла хроматограммы, путь к используемому методу, точное время записи анализа, текущую дату генерации документа и сквозную постраничную нумерацию.
{% endhint %}
