# Идентификация пиков

Настройка параметров сопоставления зарегистрированных пиков на хроматограмме с компонентами из таблицы компонентов.

**Тип идентификации**

Задает базовый критерий для поиска и привязки компонентов.

* **Время** — по абсолютному времени удерживания пика.
* **Относительное время** — с использованием относительного времени удерживания.
* **Относительный объем** — по объему удерживания.
* **Индекс** — по расчетным индексам удерживания.

**Идентификация обычных пиков**

Определяет правило выбора, если в окно идентификации компонента попадает несколько пиков.

* **Ближайший по времени** — выбирается пик, наиболее близкий к заданному времени удерживания.
* **Максимальная высота** — выбирается пик с наибольшей амплитудой сигнала.
* **Максимальная площадь** — выбирается пик с наибольшей интегрированной площадью.

**Идентификация реперных пиков**

Задает логику поиска реперных (опорных) компонентов, используемых для расчета относительных величин или корректировки шкалы времени.

* **Ближайший по времени** — выбор по минимальному отклонению от времени удерживания.
* **Максимальная высота** — выбор по максимальному значению сигнала.
* **Максимальная площадь** — выбор по максимальной площади под пиком.

**Не использовать неидентифицированные пики**

Управляет учетом неопознанных компонентов при дальнейшей обработке хроматограммы.

* **Откл.** — неидентифицированные пики учитываются при расчете полной площади или общего состава.
* **Вкл.** — пики без присвоенного имени полностью исключаются из последующих расчетов.
