# 🤡 Запуск серии анализов

Серия анализов (пакета анализов) представляет собой группу автоматических измерений, выполняемых по заданному алгоритму, при этом программное обеспечение позволяет создавать неограниченное число независимых серий внутри одного плана.

## **Серия анализов**

1. В главном окне программы перейдите к верхней ленте панели **«Управление хроматографом»**.
2. Нажмите кнопку **\[Серия анализов]**.

{% hint style="info" %}
При активации данного режима в левой части экрана открывается рабочая область **«План анализа»**. В верхней части этой области оператору доступно переключение между двумя основными вкладками: **«План серии анализов»** (для работы с очередью задач) и конфигурационной вкладкой установленного автосамплера (например, **«Конфигурация ДАЖ-4000»**). Элементы ввода одиночного паспорта пробы при этом скрываются.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (231).png" alt=""><figcaption><p>Режим серии анализов на панели управления</p></figcaption></figure></div>

## **Формирование структуры плана серии анализов**

Для создания нового пакета измерений используйте управляющие кнопки на нижней функциональной панели рабочей области:

1. Нажмите на кнопку **\[Создать серию]** `+` и в выпадающем контекстном меню выберите необходимый тип автоматизации серии:
   * **Серия анализов по готовности** — стандартный режим выполнения очереди. Переход к следующему анализу (шагу) осуществляется автоматически сразу после того, как прибор завершит текущее измерение и перевыйдет на температурные и газовые режимы готовности (уставки метода).
   * **Серия анализов по времени** — режим запуска шагов очереди со строгой привязкой к временным интервалам (интервальный запуск).
   * **Серия градуировки** — специализированный шаблон серии, предназначенный для циклической записи калибровочных стандартов с целью автоматического построения градуировочных кривых.
2. _Альтернативный вариант:_ Нажмите кнопку **\[Открыть из файла]** для загрузки в план ранее созданного и сохраненного на диске пакета заданий.
3. Сформируйте необходимую сетку пакетов в плане, нажимая кнопку создания серии требуемое количество раз.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (272).png" alt=""><figcaption><p>Создание серии анализов</p></figcaption></figure></div>

## **Параметры серии**

Каждая добавленная строка в плане представляет собой самостоятельный пакет (блок) измерений. Для настройки параметров внутри выбранного пакета выполните следующие действия:

1.  В верхней шапке серии из выпадающего списка выберите **Устройство ввода**, отвечающее за физическую инжекцию пробы в испаритель хроматографа «Кристаллюкс-4000М»:

    * **«Без устройства»** — указывает системе, что ввод образцов будет производиться оператором вручную с помощью микрошприца.
    * **«ДАЖ-4000»** (или иная модель автосамплера) — активирует автоматическую синхронизацию серии с роботизированным дозатором и открывает доступ к редактированию столбца **«Виала»**.

    <div data-with-frame="true"><figure><img src="../.gitbook/assets/image (289).png" alt=""><figcaption><p>Выбор дозатора</p></figcaption></figure></div>

    * Рядом с полем выбора дозатора расположено раскрывающееся окно выбора его **аппаратной конфигурации** (по умолчанию в системе установлена _«Стандартная»_ конфигурация).

    <div data-with-frame="true"><figure><img src="../.gitbook/assets/image (290).png" alt=""><figcaption><p>Выбор конфигурации дозатора</p></figcaption></figure></div>
2. Нажмите кнопку развертывания строки серии `∨` в правой части шапки.
3. В появившейся вложенной таблице последовательно заполните параметры для каждого анализа.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (284).png" alt=""><figcaption><p>Пример серии с ДАЖ-4000</p></figcaption></figure></div>

## **Заполнение таблицы анализов**

В развернутой таблице серии последовательно заполните параметры для каждой строки:

* **Метод** — выберите файл аналитической методики (`*.metx`) из раскрывающегося списка.
* **Повторы** — числовое поле для задания количества проводимых анализов или измерений текущей пробы из одной и той же виалы.

{% hint style="info" %}
По умолчанию установлено значение `0`. Значение `0` означает выполнение 1 (одиночного) анализа; значение `1` означает выполнение 2 последовательных анализов одной пробы; значение `N` инициирует выполнение `N + 1` анализов.
{% endhint %}

* **Назначение** — выпадающий список для выбора метрологического статуса измерения (_Анализ_, _Градуировка_, _Поверка_, _Холостой_).

{% hint style="info" %}
При выборе значения **«Холостой»** программное обеспечение осуществляет автоматический старт записи хроматограммы сразу после выхода хроматографа на режим готовности. Принудительный ручной ввод или внешняя команда от автосамплера в данном режиме не требуются.
{% endhint %}

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (279).png" alt=""><figcaption><p>Пример серии анализов</p></figcaption></figure></div>

* Поля **Проба**, **Объем**, **Оператор** и **Комментарий** заполняются оператором вручную в произвольном формате по желанию (согласно требованиям внутренних лабораторных инструкций).
* **Виала** — укажите физический номер ячейки (гнезда) на карусели автосамплера **(актуально только при выбранном устройстве ввода**). Допускается задание номеров в произвольном, нелинейном порядке.
* **Паспорт СО** — столбец, появляющийся **только в специализированной «Серии градуировки»** вместо базового списка назначений. Требует обязательного выбора предварительно созданного цифрового паспорта стандартного образца для автоматической привязки качественного состава, концентраций и неопределенности компонентов.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (285).png" alt=""><figcaption><p>Таблица серии градуировки</p></figcaption></figure></div>

* При необходимости добавления новой пробы в этот же пакет нажмите кнопку **\[Добавить анализ]** `+` в правой части шапки серии. Для сохранения настроенного плана на диске ПК нажмите кнопку **\[Сохранить в файл]** на нижней панели управления.

## Редактирование и удаление элементов плана

Оператор может изменять состав очереди задач непосредственно перед запуском или во время паузы:

* **Глобальное отключение пакета:** Переведите большой тумблер в левой части шапки серии в положение **«Выкл.»** (серый индикатор). Программа полностью пропустит эту серию и все вложенные в неё анализы.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (286).png" alt=""><figcaption><p>Вторая серия будет пропущена целиком</p></figcaption></figure></div>

* **Локальное отключение пробы:** Снимите флажок (чекбокс) в крайнем левом столбце напротив конкретной строки внутри развернутой таблицы серии. Программа пропустит этот анализ, не нарушая общую нумерацию плана.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (287).png" alt=""><figcaption><p>В серии будет выполняться анализ только по первому методу</p></figcaption></figure></div>

* **Удаление серии целиком:** Нажмите экранную кнопку **\[Удалить серию]** (иконка в виде корзины) в правой части шапки серии.
* **Удаление одного анализа:** Наведите курсор на требуемую строку внутри серии, нажмите правую кнопку мыши (**ПКМ**) и в контекстном меню выберите команду **«Удалить анализ»**.

## Запуск и управление циклом серии

1. Нажмите кнопку **\[Запуск серии]**, расположенную на нижней панели вкладки **«План серии анализов»**.
2. Сразу после старта функционал нижней панели динамически изменяется — на ней активируются элементы оперативного управления запущенным циклом:
   * **Кнопка \[Пауза серии]** — инициирует контролируемую приостановку. Текущий активный анализ дописывается до конца и корректно сохраняется в базу данных, после чего выполнение плана приостанавливается до повторного нажатия кнопки старта.
   * **Кнопка \[Стоп серии]** — осуществляет экстренную остановку. Запись текущей хроматограммы прерывается мгновенно, ввод новых проб блокируется, выполнение всего плана аннулируется. Данные прерванного анализа могут быть утеряны.
3. Дождитесь автоматического перехода текущего технологического этапа в статус **«Ввод пробы»** (отображается в строке состояния ПО «NetChrom» в правом верхнем углу под именем рабочего метода) и непрерывного свечения индикатора **«Готов»** на корпусе хроматографа «Кристаллюкс-4000М».
4. Осуществите ввод образца в соответствии с выбранной конфигурацией:
   * **При работе без устройства (ручной ввод):** Программный комплекс переходит в режим ожидания. Введите образец в испаритель вручную с помощью микрошприца и нажмите физическую кнопку **«Старт»** на панели прибора (или кнопку запуска анализа в ПО).
   * **При работе с автосамплером:** Программа автоматически подаст команду на дозатор. Устройство выполнит промывку шприца, забор пробы из заданной виалы и инжекцию, после чего автоматически запустится запись данных.

{% hint style="warning" %}
При последовательном выполнении плана ПО «НетХром» производит передачу параметров метода в контроллер автоматически при переходе к каждой новой строке серии. Если в следующей строке задан другой метод `*.metx`, система кратковременно приостановит цикл до момента стабилизации физических параметров прибора на новых уставках.
{% endhint %}

## Мониторинг хода выполнения измерений

В процессе отработки запущенного плана программный комплекс осуществляет непрерывное визуальное информирование оператора:

* Строка анализа, выполняемого хроматографом в текущий момент времени, автоматически подсвечивается в таблице **полупрозрачным желтым фоном**.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (288).png" alt=""><figcaption><p>Текущий анализ</p></figcaption></figure></div>

**Принципиальное отличие результатов обработки данных по завершении серии**

* **При использовании «Серии градуировки»:** Программа выполняет сквозной автоматический цикл. Сразу после окончания записи хроматограммы система самостоятельно идентифицирует пики, сопоставляет их с данными привязанного _Паспорта СО_ и **автоматически строит (вносит) новые градуировочные точки** в графики зависимостей метода.
* **При использовании ручного назначения «Градуировка» в обычной серии:** Автоматический обсчет и изменение калибровочных графиков не инициируются. Программа просто сохраняет файлы с маркером калибровки. После окончания серии оператор обязан **вручную открыть каждый файл, разметить пики и принудительно внести градуировочные точки** через редактор метода.

## Конфигурация дозатора ДАЖ-4000

Вкладка **«Конфигурация ДАЖ-4000»** предназначена для создания, редактирования и хранения индивидуальных аппаратных методов работы жидкостного автоматического дозатора (автосамплера). Параметры вкладки определяют механическое поведение робота на всех этапах цикла: от забора жидкого образца до промывки измерительной системы.

**Управление сохраненными методами дозатора**

В левой части вкладки отображается вертикальная панель **«Сохраненные методы»**, где хранится база данных созданных пользователем конфигураций (по умолчанию в списке присутствует один базовый метод — _«Стандартный»_).

Для оперативного управления методами используйте функциональные кнопки, расположенные в самом низу левой панели:

* **Новый метод** — инициализирует создание чистого шаблона настроек автосамплера со значениями параметров по умолчанию.
* **Удалить метод** — безвозвратно стирает выбранную конфигурацию дозатора из локальной базы данных программного комплекса.
* **Создать дубликат** — полностью копирует все настройки текущего метода в новый файл. Функция используется оператором для быстрого создания однотипных методик с минимальными отличиями (например, для изменения только объема ввода или количества промывок шприца).

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (240).png" alt=""><figcaption><p>Управление конфигурациями дозаторов</p></figcaption></figure></div>

**Конфигурирование параметров метода дозатора**

Настройка физических параметров работы автосамплера ДАЖ-4000 выполняется в правой части вкладки. Ниже приведены детальные описания всех доступных полей, алгоритмов выпадающих списков.

**Блок «Набор пробы»**

Параметры этой группы регламентируют механику и динамику забора жидкого образца из рабочей виалы в цилиндр микрошприца:

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (291).png" alt=""><figcaption><p>Стандартные значения параметров ДАЖ-4000</p></figcaption></figure></div>

* **Название метода** — текстовое поле для идентификации конфигурации.
* **Тип набора** — выпадающий список, определяющий физический алгоритм движения плунжера шприца и чередования слоев жидкости в цилиндре:
  * **Простой набор** — стандартный режим работы. Автосамплер опускает иглу в рабочую виалу и за один или несколько тактов (в зависимости от количества прокачек) набирает заданный объем исследуемого образца.
  * **Отбор с внутр. стандартом** — специализированный автоматизированный режим для выполнения количественного расчета методом внутреннего стандарта.
    * При активации режима отбора с внутренним стандартом интерфейс блока динамически расширяется четырьмя дополнительными полями для настройки параметров калибровочного компонента и воздушного разделения сред:
      * Объем стандарта — числовое значение объема раствора внутреннего стандарта, который шприц забирает в первую очередь.
      * Номер виалы со стандартом — цифровой индекс ячейки на карусели автосамплера, в которой физически установлен флакон с чистым раствором внутреннего стандарта.
      * Воздушный промежуток — выпадающий список, определяющий конфигурацию воздушной отсечки между слоем стандарта и слоем пробы во избежание их преждевременного диффузионного смешивания внутри иглы.
      * Объем воздушного промежутка — объем воздуха (в делениях шкалы шприца), втягиваемый поршнем после забора стандарта для формирования изолирующей прослойки.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (293).png" alt=""><figcaption><p>Отбор с внутренним стандартом</p></figcaption></figure></div>

* **Скорость набора** — скорость перемещения поршня вверх при взятии дозы. Стандартное значение — `5`.
* **Количество прокачек** — число предварительных тактов движения плунжера вверх-вниз внутри виалы с пробой. Используется для вытеснения пузырьков воздуха из канала иглы. Стандартное значение — `3`.
* **Задержка шприца в пробе (сек.)** — время удерживания иглы в неподвижном состоянии внутри жидкости после завершения хода плунжера (необходимо для стабилизации давления в шприце и дегазации вязких сред). Стандартное значение — `0`.
* **Объем отбора** — общий объем жидкости, затягиваемый в цилиндр шприца при первичном наборе. Стандартное значение — `7`.
* **Объем ввода** — целевой объем дозы пробы, который будет непосредственно впрыснут в испаритель хроматографа «Кристаллюкс-4000М». Стандартное значение — `1`.

**Блок «Ввод пробы»**

Группа параметров отвечает за динамику инжекции и испарения образца в горячей зоне испарителя прибора:

* **Скорость ввода** — скорость движения поршня шприца вниз при совершении укола. Высокая скорость минимизирует размытие начальной зоны пробы на входе в колонку. Стандартное значение — `100`.
* **Время выдержки до ввода (сек.)** — время нахождения иглы в испарителе до момента выталкивания пробы (используется для предварительного прогрева иглы). Стандартное значение — `0`.
* **Время выдержки после ввода (сек.)** — время удержания иглы внутри испарителя после укола, необходимое для полного испарения и переноса остатков жидкой фазы с внутренних стенок иглы в поток газа-носителя. Стандартное значение — `1`.

**Блок «Промывка шприца»**

Параметры очистки внутренней измерительной системы чистыми растворителями для исключения эффекта «памяти» (переноса компонентов предыдущей пробы в последующий анализ) и защиты иглы от залипания плунжера:

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (295).png" alt=""><figcaption><p>Варианты промывки шприца растворителем</p></figcaption></figure></div>

* **Переключатель Вкл./Выкл.** — активирует или полностью отключает цикл промывки шприца растворителями. По умолчанию — `Вкл.`&#x20;
* **Промывка растворителем** — раскрывающийся список, определяющий временную привязку и цикличность автоматической очистки шприца чистым растворителем относительно момента инжекции:
  * **Нет** — автоматическая промывка шприца растворителем полностью отключена. Режим используется только при экспресс-анализах летучих сред, не склонных к сорбции на стенках иглы и цилиндра, либо при ручной регламентной очистке.
  * **До ввода** — автосамплер выполняет установленное количество циклов промывки растворителем _непосредственно перед_ забором новой пробы из рабочей виалы. Позволяет гарантировать чистоту шприца перед началом отбора.
  * **После ввода** — цикл промывки растворителем инициируется _сразу после_ совершения укола и извлечения иглы из испарителя хроматографа «Кристаллюкс-4000М». Режим необходим для оперативного удаления остатков тяжелых или полимеризующихся компонентов из канала шприца, предотвращая заклинивание поршня.
  * **До и после ввода** _(установлен по умолчанию)_ — комбинированный и наиболее надежный режим. Включает в себя оба цикла очистки, обеспечивая максимальную метрологическую достоверность и полное исключение эффекта «памяти» шприца при чередовании проб с сильно различающимися концентрациями.
* **Виала для промывки** — указание литерного индекса целевого флакона с чистым смывным растворителем на карусели автосамплера А или В. Стандартное значение — `А`.
* **Объем растворителя** — количество очищающей жидкости, набираемой за один такт промывки. Стандартное значение — `8`.
* **Количество сливов** — число полных циклов набора растворителя и его последующего сброса в специализированную виалу-отход С. Стандартное значение — `3`.

**Блок «Промывка пробой»**

Параметры предварительного ополаскивания канала шприца исследуемым образцом перед его финальным набором, что гарантирует репрезентативность вводимой дозы:

* **Переключатель Вкл./Выкл.** — активирует режим предварительного смачивания и скользящей очистки шприца целевым образцом. По умолчанию — `Вкл.`&#x20;
* **Количество сливов** — число циклов забора пробы из рабочей виалы и её сброса в отходы D до совершения укола. Стандартное значение — `3`.

{% hint style="info" %}
&#x20;Увеличение количества прокачек, сливов пробы и промывок растворителями существенно повышает точность и сходимость результатов измерений, однако увеличивает общее время выполнения одного шага серии анализов и приводит к повышенному расходу смывных реагентов.
{% endhint %}
